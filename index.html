Critérios antes da publicação

O modelo entregue apresenta divergências com o DER e os requisitos. Este dicionário reproduz as chaves e tipos do SQL sem corrigi-los implicitamente. A classificação LGPD e a matriz RBAC são inferências profissionais: exigem validação do controlador e implementação real no backend, respectivamente.

Este site contém apenas metadados estruturais; não disponibilize dados operacionais, pessoais, credenciais nem cópias integrais do banco de produção no GitHub Pages.
